# Codex Reset Tracker

A small static site showing the time since the last global OpenAI Codex usage-limit reset, the full reset history, and a pace helper.

Live: https://anilkumarnandamuri.github.io/codex-reset-tracker/

**Not affiliated with or endorsed by OpenAI.** Unofficial, community-made.

## Data source
Resets are compiled from public announcements by @thsottiaux on X (`data/resets.json`, generated by `scripts/update_resets.py`). Each entry links to the original post.
